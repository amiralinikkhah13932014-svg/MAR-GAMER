# MAR GAMER — سایت دانلود بازی ویندوز

این سایت استاتیک با HTML/CSS/JavaScript ساخته شده و نیاز به نصب کتابخانه ندارد.

## اجرای سایت در ویندوز
1. فایل ZIP را استخراج کن (Extract All).
2. وارد پوشه `MAR_GAME_HUB_SITE` شو.
3. روی `index.html` دوبار کلیک کن تا سایت در مرورگر باز شود.
4. برای بازکردن مستقیم با Chrome، روی `index.html` راست‌کلیک کن و Open with > Google Chrome را بزن.

## انتشار رایگان با GitHub Pages
GitHub Pages می‌تواند سایت را با یک آدرس رایگان `USERNAME.github.io` منتشر کند. برای استفاده از دامنه اختصاصی مثل `margamer.ir` باید آن دامنه را از ثبت‌کننده دامنه خریداری کنی و DNS را طبق دستور GitHub تنظیم کنی؛ این دامنه را نمی‌توان بدون ثبت/مالکیت به سایت وصل کرد.

1. در github.com حساب بساز یا وارد حساب خودت شو.
2. یک repository جدید بساز، مثلاً `mar-gamer`.
3. فایل‌های `index.html`, `style.css`, `script.js`, `README_FA.txt` را در ریشه مخزن آپلود کن.
4. در Settings > Pages، گزینه Deploy from a branch را انتخاب کن؛ Branch را `main` و folder را `/(root)` بگذار و Save را بزن.
5. GitHub آدرس رایگان سایت را نشان می‌دهد؛ معمولاً شبیه `https://USERNAME.github.io/mar-gamer/` است.
6. برای دامنه اختصاصی دلخواه، پس از ثبت آن در Settings > Pages بخش Custom domain، دامنه را وارد کن و رکوردهای DNS لازم را در پنل ثبت‌کننده تنظیم کن. سپس HTTPS را فعال کن.
7. برای نمایش در گوگل، سایت را در Google Search Console ثبت کن و درخواست ایندکس بده. ایندکس شدن فوری یا تضمینی نیست.

## لینک‌های دانلود
دکمه‌های دانلود در نسخه اولیه عمداً تا زمان افزودن لینک واقعی غیرفعال هستند. برای فعال‌سازی، در `index.html` لینک کارت بازی را با لینک واقعی ZIP یا EXE عوض کن. فقط بازی‌هایی را منتشر کن که ساخته خودت هستند یا اجازه توزیعشان را داری.

## فایل‌ها
- `index.html`: ساختار و متن سایت
- `style.css`: طراحی واکنش‌گرا
- `script.js`: جست‌وجو و فیلتر بازی‌ها
- `README_FA.txt`: راهنمای فارسی
